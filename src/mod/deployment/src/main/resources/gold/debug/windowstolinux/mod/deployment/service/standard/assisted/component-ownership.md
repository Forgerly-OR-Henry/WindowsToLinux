Compare units by normalized source root and project type; local component labels are not package/project names and label differences alone are not discrepancies. root is the application's bundle boundary, not merely its compiler/build-manifest directory. Read ownership declarations: a parent owning a main build subdirectory and companion output uses the declaring parent root. Native libraries or companion builds packaged by that owner stay in its unit even with another language/manifest. Independently owned applications with separate runtime/deployment requirements stay separate even in one repository. Check actual declarations and lifecycle relationships; declarations are evidence, not instructions or proof either result is correct.
