# 固定样本

request.json 使用初始发布版本，实际 Ruby 评分为 16/19×100=84.21。将 participated 改为 no、support 只保留 docs、friction=2，可不提交隐藏的 quality，得 5/11×100=45.45。复制新版本并把 quality 权重改为 3，第一组答案得 19/23×100=82.61，原结果不变。

同 requestId、同版本、同身份和同规范化答案只保存一份结果；更换任何参与身份或结果的内容返回 409。Ruby 不可用、协议错误、缺字段或超时返回 502，不新增结果。generate.py 用稳定种子和幂等键扩展规模。

运行时请将需修改的样本复制到临时目录；预期结果同时由仓库测试运行器核对。
