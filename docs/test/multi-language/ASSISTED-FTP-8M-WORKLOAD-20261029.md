# 后续 FTP 验收负载：8 MiB

用户因网络速度明确调整后续单文件负载为精确 8 MiB（8388608 字节）。当前 R06 仍冻结原 64 MiB，本文与本改动不作用于活动轮。后续新轮须另冻结实际提交、编译产物、参数及 8 MiB policy；旧 64 MiB 与新 8 MiB 结果不可拼接或互称同口径通过。

1 MiB 分片不变；从 payload/chunk 推导共 8 片，原四分之一部分上传重启比例对应先 2 片、重启后续 6 片。两版本正常 16 次 chunk，加取消、错误 SHA、下游中断各 1 次，共 19 组正常 chunk trace；重复/冲突请求另有原断言。

双版本、五次完整下载及 SHA（v1/v1/v2/v1/v2）、10 并发 complete、重复冲突/提前 complete 拒绝、取消持久化、重启续传、错误 SHA 失败、真实 backend STOP/START/502、交付与额外清理均保留。产品实现、分阶段期限、普通 HTTP 期限及独立 APP/fresh grant/CAS 不改。较小文件减少覆盖的持续负载时间，不证明原 64 MiB 慢因已修复，也不声称覆盖 BUSINESS.md 全矩阵。
