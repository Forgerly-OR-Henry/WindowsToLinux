# 保留现有动效的流畅度优化验证

日期：2026-10-29。环境：Windows 11、Oracle JDK 21.0.10、Maven 3.9.12、当前 FlatLaf 3.7.1。

## 改动与线程边界

原有动画视觉、时长、缓动、反向动作及公开 `UiMotion` 接口保留。活跃动画改用一个共享 Swing 定时器，无活动动画时停止；单个回调异常隔离后报告，隐藏、关闭、取消及锁定继续遵守原生命周期。控件、布局、绘制在 EDT，耗时业务及持久化继续通过既有后台任务执行。

侧栏只在整数宽度变化时更新布局尺寸；抽屉按实际几何变化布局并保留所属容器的其他布局职责，子组件尺寸变化仍正常校验；弹窗直接调整真实内容边界，保留命中区域。导航复用原按钮，选中变化不发布排序数据事件；隐藏排序页合并发布通知。隐藏服务器页停止展示轮询，恢复时立即同步，不影响已接纳任务。任务清单及详情跳过不变快照，包含空状态；跨锁定代次的旧查询不回填，并在解锁后补读新代状态。

## 同条件调度对照与前后采样

先运行新增的可选采样测试，再改生产代码。两轮均使用1280×800窗口、中文、浅色、100%应用缩放、隔离H2，无部署、传输或远端请求；真实宿主页面与一个无业务的Mod测试页面，按同一循环切页、侧栏伸缩、抽屉快速反向及弹窗开合。

纯Swing定时器对照（各89个预热后样本）显示，16ms请求平均29.999ms、p95为31.662ms；10ms请求平均15.530ms、p95为16.160ms；8ms请求平均15.465ms、p95为15.968ms。因此将原计划的共享16ms唤醒改为10ms，以改善本机定时量化；各动画仍以单调时钟计算真实经过时间，不改变视觉时长，不修改全局系统定时精度。

| 场景 | 回调平均间隔：优化前→后（ms） | 回调p95：优化前→后（ms） | 超过33ms回调：优化前→后 |
| --- | --- | --- | --- |
| 页面切换 | 31.183 → 16.348 | 46.170 → 26.564 | 12/100 → 3/194 |
| 侧栏伸缩 | 31.723 → 16.274 | 46.111 → 17.986 | 9/82 → 3/160 |
| 抽屉快速反向 | 30.624 → 16.306 | 32.134 → 30.247 | 3/70 → 0/132 |
| 弹窗 | 30.312 → 16.512 | 31.920 → 30.423 | 0/54 → 0/99 |

EDT排队p95分别为：空闲0.355→0.315ms，切页2.201→6.483ms，侧栏0.842→0.389ms，抽屉0.304→0.386ms，弹窗0.269→0.277ms。绘制批次耗时p95分别为：切页6.752→11.753ms，侧栏5.112→6.866ms，抽屉4.259→5.895ms，弹窗2.502→2.714ms。主要测得收益是动画调度节奏，绘制和排队耗时并非全面下降，未测量或宣称总CPU占用下降。

回调间隔由只记录时间的 `DesktopMotion` 观察者采集；排队延迟由最多一个待处理的20ms后台探针采集；绘制批次为 `RepaintManager.paintDirtyRegions` 调用耗时，可能包含空批次。这些指标不等于屏幕呈现帧率，也没有垂直同步或GPU呈现时间数据。原始CSV、测试日志及动图保存在本地 `.ai-workspace/evidence/ui-motion-performance-20261029/` 和相邻同名前缀日志中。

## 定点验证

验证只筛选改动直接相关的方法和测试类，未执行全项目或整个模块测试套件。

- 动画：共享时钟空闲停止、错误隔离、取消同批回调、关闭动画即时完成、抽屉重定向与反向、弹窗真实命中区域、侧栏连续运动及底部转位。
- 展示：导航按钮/图标实例不变且不发布选中事件；隐藏排序页通知合并；菜单不变不校验布局；任务空快照不重建、变更行更新、选择及语言刷新保持。
- 通知边界：Mod操作控件仍订阅可用状态，排序页单独订阅元数据；偏好读取完成后恢复操作按钮，不引发排序重读。
- 集成：隐藏服务器页停止展示轮询且不取消已接纳工作；服务器异步完成不越过锁代；任务旧查询跨锁定或关闭不能恢复私人内容；排序离页保存保持作者页面惰性创建。
- 真实Swing几何矩阵：中英文、浅深主题、100%/150%缩放、两种窗口尺寸下，服务器和任务抽屉开合/快速反向/全局关闭动画通过。侧栏额外覆盖100%/150%/200%缩放。代表性服务器与任务动图已生成并检查。

运行性能采样时需明确启用；常规测试默认跳过该可选测试：

本轮共32个不同定点测试方法最终通过，包含两种性能采样和一个窗口几何矩阵；编译、IntelliJ格式检查及改动差异检查通过。早期失败与修正保留在原日志中。本次验证进程已退出，启动时间早于本次任务的ASSISTED验收进程保留。真实产品数据、真实Linux/SSH业务及全部第三方Mod页面的性能不在本轮验证范围。
