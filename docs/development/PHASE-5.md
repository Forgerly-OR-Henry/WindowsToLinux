## 1. 五期目标

五期只提供内部测试使用的单实例 Web 功能服务台。浏览器可以提交源码/Git、服务器、分析、部署、受管生命周期、备份和迁移任务，并在关闭页面后继续执行。Web 服务台复用 `shared` 的业务规则，但本期不实现登录、管理员初始化、会话、CSRF、公开网络部署或其他正式上线认证能力。

五期完成的是与桌面 App 主要业务能力对等的内部功能区，而不是可上线网站。公开官网首页、产品介绍、公开文档导航、正式下载入口、登录认证和服务入口外壳统一在六期建设；届时官网可以把五期服务台作为最重要的受保护功能入口。

Web 后端可以读取上传或 Git 快照做静态分析，但不得在 Web 主机安装用户项目依赖、运行用户项目脚本或构建。用户项目仍只在目标 Linux 构建。WindowsToLinux Web 自身的前端/后端发布构建属于产品发布流程，不属于用户项目构建。

## 2. 内部测试运行边界

- 后端必须以明确的内部测试模式启动，默认只绑定 `127.0.0.1`/`::1`；五期不提供监听公网、局域网所有地址、反向代理或正式服务安装模式。
- 无登录状态下直接进入功能服务台，因此只能在开发机或受控自动化测试进程中使用；启动页和控制台持续显示“内部测试，禁止上线”。
- 单实例后端独占临时或专用测试 SQLite 和受管工作目录，不支持多个后端共享数据库或目录。
- 运行数据、SQLite、上传工作区、备份和日志使用明确分离的测试位置，不读取桌面正在使用的数据目录。
- 后端启动时验证单实例锁、目录、数据库 schema 和磁盘下限；失败即停止，不回退到任意临时目录。
- 即使只用于内部测试，也禁止宽松 CORS、JSONP、跨站表单副作用和浏览器直连 SSH。状态修改只接受同源 JSON 请求及固定自定义请求头，避免普通网页向回环服务发起简单跨站请求；这不构成正式认证。

五期没有安全上线形态。需要远程浏览器、局域网共享、HTTPS、反向代理、登录、用户身份或正式服务安装时，必须等待六期。

## 3. Web 接口边界

内部 API 使用 `/api/v1/` 前缀。具体 JSON 字段和 OpenAPI 在实现对应纵向切片时冻结，本期先固定行为：

- 服务器、AI、上传/Git、分析、部署、受管应用、生命周期、备份、恢复、迁移、设置和任务查询；不包含认证、会话或管理员接口。
- 分析、部署、生命周期修改、备份、恢复和迁移提交后返回任务 ID；后台执行，SSE 只传输结构化脱敏事件。
- 只读状态刷新必须查询目标服务器并返回观测时间和未知/异常状态，不能只返回数据库缓存。
- 状态改变只能使用 POST/PUT/PATCH/DELETE；GET/HEAD/OPTIONS 必须只读且无副作用。
- 错误返回稳定错误标识、用户可执行说明和关联 ID，不返回异常堆栈、SQL、内部路径、命令全文或秘密。

禁止提供任意 Shell、浏览器直连 SSH/SFTP、原始凭据回读、任意文件路径、任意 systemd/容器操作，以及由客户端覆盖任务状态或标记成功的接口。

## 4. 上传、Git 与受管工作区

### 4.1 上传

- 浏览器只可读取用户主动选择的文件/目录，不能扫描访问者电脑。
- 服务端采用流式上传，限制单文件、单项目、单备份、总空间、成员数量、并发数和保留时间，不把完整大文件读入 Java 堆。
- ZIP/`tar.gz` 解压拒绝绝对路径、穿越、越界链接、特殊文件、重复覆盖、压缩炸弹和超限路径。
- 上传完成前不可进入分析；失败/过期临时目录只有在无有效任务/恢复点引用并通过归属标记后才能清理。

### 4.2 静态分析与目标机构建

- 上传/Git 快照在 Web 工作区只做静态读取、归档和摘要；禁止执行 Hook、Wrapper、包管理器、项目二进制或构建脚本。
- 后端将已校验源码发送到目标 Linux，或让目标机取得同一固定 Commit，并复核摘要后构建。
- Web 主机不能作为用户项目的“临时构建机”或失败回退构建位置。

## 5. 持久化任务

任务至少包含：等待、分析中、等待用户决定、执行中、正在取消、已取消、成功、失败、被系统中断、需要重新验证。

- 浏览器断开不取消任务；SSE 断线后可以按事件序号继续，最终状态也可普通查询。
- 同一目标服务器上的修改任务互斥；只读任务仅在资源限制内并行。
- 后端重启后扫描未终结任务。只有具有幂等证据和安全恢复点的步骤可继续，其余进入“需要重新验证”。
- 等待用户决定具有过期时间；过期安全停止。取消是受控状态迁移，不直接杀死到未知状态。
- 任务保存计划摘要、步骤输入摘要、远端结果、版本指针、结构化事件和失败证据；秘密在持久化前脱敏。
- API/SSE 客户端无权直接修改任务状态、步骤游标或成功结果。

## 6. 内部测试凭据

- 五期不保存管理员账号或密码。`web/secret` 只为内部功能测试处理 SSH/Git/AI/备份相关凭据，不承担上线认证。
- 测试主密钥只通过测试进程环境或权限受限的临时文件提供，不进入 SQLite、普通数据备份、日志、事件或 HTTP；测试结束后可以安全销毁。
- 保存后只向浏览器返回名称、非敏感元数据、已配置状态和更新时间，永不回传原始值。
- 测试主密钥丢失时不能伪造恢复，必须要求重新配置受影响凭据；数据库恢复结果需要明确指出凭据不可用。
- 桌面与 Web 不同时打开同一个 SQLite 或工作目录。迁移配置使用经过验证的导入/导出，不共享正在使用的数据文件。
- 不得因为五期没有登录而把秘密改为明文落库、返回浏览器、写入 URL 或输出到测试报告；这些数据边界属于业务安全，不是可后置的登录功能。

## 7. 前端范围

`web/frontend` 使用 Vue 3、TypeScript、Vite，单元测试使用 Vitest，关键流程使用 Playwright。前端只通过 HTTP/SSE 使用 `web/api`，不依赖 Java 模块或直接访问数据库、文件、SSH。

内部测试功能入口覆盖部署、已部署应用、服务器、AI、备份/迁移、任务和设置，但不建设大型专业运维控制台。页面必须区分浏览器电脑、Web 主机和目标 Linux，说明动作影响、失败原因和下一步，不展示原始异常或用隐藏失败制造简单感。

五期前端直接进入服务台功能路由，不实现初始化、登录或账号页面；根路径只在回环内部测试模式显示服务台和醒目的非生产警告，不制作官网式公开首页、产品营销页面、公开下载页或发布版本页。

当前仓库中的页面只是可构建骨架，不代表任何 Web 业务已经实现。

## 8. Web 自身迁移测试

五期不建设正式发布包、镜像或自动更新器，只使用测试构建验证数据库迁移和失败回滚顺序：

```text
停止接收新修改任务
→ 等待任务进入安全状态
→ 备份 SQLite、应用数据和版本信息
→ 测试人员替换本地测试构建
→ 新版本执行迁移前检查和版本化数据库迁移
→ 启动健康检查
→ 成功恢复任务；失败由管理员切回旧包/镜像并恢复旧数据库
```

测试必须保留可操作的回滚证据和步骤，但不能在运行进程内覆盖自身。数据库迁移失败时停止启动，不让旧程序读取已迁移失败的数据结构。正式签名包、人工上线升级和发布下载属于六期。

## 9. 实施顺序

1. 完成服务台前端骨架门禁和 `web` 模块装配基础，不建设公开官网页面。
2. 实现仅回环内部测试模式、专用 SQLite、测试主密钥和模块装配。
3. 实现受管文件、上传和 Git 静态快照边界。
4. 实现持久化任务状态机、恢复和 SSE 事件。
5. 接入服务器、分析、部署和生命周期，共享前四期规则。
6. 接入备份/迁移及本地迁移回滚测试，完成浏览器功能和业务安全负向测试。

## 10. 五期不包含

- 登录、管理员初始化、会话、Cookie、CSRF、近期认证、密码修改、速率限制、可信代理、Host/HTTPS 公网部署和安全审计；这些上线认证能力统一属于六期。
- 官方 SaaS、多用户、多租户、角色权限、公开注册或找回密码邮件。
- 多节点后端、共享 SQLite、分布式任务队列或 Kubernetes。
- 浏览器终端、远程文件管理器、任意服务/容器管理和通用监控。
- 在 Web 主机执行用户项目或把 Web 主机当作构建回退。
- 自动 DNS/域名/云账号接管或 Web 进程自动替换自身。
- 公开官网主页、产品介绍、公开文档入口、正式下载页面、官方发布清单或桌面更新服务；这些统一属于六期。

## 11. 验收标准

### 11.1 内部运行边界

- [ ] 无认证服务只能在显式内部测试模式启动，默认只监听回环地址，并持续显示禁止上线提示。
- [ ] 五期不存在登录、管理员、会话或公开官网路由；宽松 CORS、简单跨站副作用和非回环监听被静态与启动测试阻止。
- [ ] 专用测试 SQLite、工作目录和测试主密钥不与桌面数据共享，秘密不以明文进入数据库、HTTP、日志或报告。

### 11.2 文件和任务

- [ ] 大文件流式处理，路径穿越、链接、特殊文件、压缩炸弹、超限和清理越界被阻止。
- [ ] Web 主机从不执行用户项目代码，目标机源码摘要与分析快照一致。
- [ ] 浏览器断开和后端重启不会把任务误标成功；只安全恢复可幂等步骤。
- [ ] SSE 可恢复且只包含脱敏事件，客户端不能伪造任务状态。

### 11.3 业务与迁移

- [ ] Web 部署、生命周期、备份和迁移复用前四期规则，远端状态来自实时查询。
- [ ] 浏览器不能读取原始 SSH/Git/AI/备份凭据，主密钥不进入 SQLite 或普通备份。
- [ ] 前端类型检查、Vitest、生产构建和关键 Playwright 流程通过。
- [ ] 本地测试构建的迁移或健康失败具有经过验证的旧构建和旧数据库回滚路径；不据此宣称正式升级可用。
