## 1. 五期目标

五期提供用户自行部署的单实例、单管理员 Web 版本。浏览器可以提交源码/Git、服务器、分析、部署、受管生命周期、备份和迁移任务，并在关闭页面后继续执行。Web 复用 `shared` 的业务规则，不建设官方 SaaS、多租户或通用服务器控制台。

Web 后端可以读取上传或 Git 快照做静态分析，但不得在 Web 主机安装用户项目依赖、运行用户项目脚本或构建。用户项目仍只在目标 Linux 构建。WindowsToLinux Web 自身的前端/后端发布构建属于产品发布流程，不属于用户项目构建。

## 2. 部署形态与开始条件

- 单实例后端独占 SQLite 和受管工作目录，不支持多个后端共享数据库或目录。
- 支持由管理员部署为 Windows 服务、Linux systemd 服务或 Docker/Podman 单容器；公网访问必须使用 HTTPS。
- 反向代理终止 TLS 时，只信任显式地址/CIDR 的代理及规定转发头，同时验证 Host；不接受任意客户端伪造的协议和来源地址。
- 运行数据、SQLite、上传工作区、备份、日志和主密钥使用明确分离的受限位置。
- 后端启动时验证单实例锁、目录权限、主密钥、数据库 schema 和磁盘下限；失败即停止服务。

## 3. 首次管理员初始化

### 3.1 一次性令牌

- 尚无管理员时，后端生成高熵一次性初始化令牌，默认有效 15 分钟，只输出到服务器控制台或权限仅服务账号可读的临时文件。
- 日志聚合默认不得采集完整令牌；界面和 API 不提供匿名查询令牌的能力。
- 初始化请求必须同时提交令牌和新管理员密码，并受来源/速率限制。令牌错误、过期或已用均返回无差异安全错误。
- 成功创建唯一管理员后，在事务中消费令牌并永久关闭初始化端点；重启或删除临时文件不能重新打开。
- 初始化前除健康和初始化所需最小端点外，服务器、任务、文件、凭据和设置接口全部拒绝访问。

### 3.2 管理员密码

密码通过 `web/secret` 使用带独立随机盐和版本化参数的适应性密码哈希保存，不使用可逆加密。修改密码、凭据、主密钥状态、恢复或迁移等高风险动作要求近期认证。

## 4. Web 接口边界

内部 API 使用 `/api/v1/` 前缀。具体 JSON 字段和 OpenAPI 在实现对应纵向切片时冻结，本期先固定行为：

- 认证/会话、服务器、AI、上传/Git、分析、部署、受管应用、生命周期、备份、恢复、迁移、设置和任务查询。
- 分析、部署、生命周期修改、备份、恢复和迁移提交后返回任务 ID；后台执行，SSE 只传输结构化脱敏事件。
- 只读状态刷新必须查询目标服务器并返回观测时间和未知/异常状态，不能只返回数据库缓存。
- 状态改变只能使用 POST/PUT/PATCH/DELETE；GET/HEAD/OPTIONS 必须只读且无副作用。
- 错误返回稳定错误标识、用户可执行说明和关联 ID，不返回异常堆栈、SQL、内部路径、命令全文或秘密。

禁止提供任意 Shell、浏览器直连 SSH/SFTP、原始凭据回读、任意文件路径、任意 systemd/容器操作，以及由客户端覆盖任务状态或标记成功的接口。

## 5. 会话、CSRF 与浏览器安全

- 使用服务端会话。会话 Cookie 设置 `HttpOnly`、显式 `SameSite=Lax`、限定 Path；HTTPS 环境必须设置 `Secure`。
- 所有状态修改请求启用 CSRF；SPA 从受控同源端点取得 CSRF 值并通过自定义请求头提交，不把令牌放入 URL。
- 登录具有速率限制、渐进延迟和安全审计；响应不区分账号不存在、密码错误或令牌状态细节。
- 会话空闲和绝对超时分别配置；退出、改密、主密钥变化和管理员安全事件使相关会话失效。
- 不在 localStorage、sessionStorage、URL、前端日志或页面源码保存密码、私钥、API Key、SSH 口令或长期高权限令牌。
- 设置 Content Security Policy、frame 限制、内容类型保护和合理 Referrer Policy；富文本和构建日志按纯文本/严格转义呈现。

## 6. 上传、Git 与受管工作区

### 6.1 上传

- 浏览器只可读取用户主动选择的文件/目录，不能扫描访问者电脑。
- 服务端采用流式上传，限制单文件、单项目、单备份、总空间、成员数量、并发数和保留时间，不把完整大文件读入 Java 堆。
- ZIP/`tar.gz` 解压拒绝绝对路径、穿越、越界链接、特殊文件、重复覆盖、压缩炸弹和超限路径。
- 上传完成前不可进入分析；失败/过期临时目录只有在无有效任务/恢复点引用并通过归属标记后才能清理。

### 6.2 静态分析与目标机构建

- 上传/Git 快照在 Web 工作区只做静态读取、归档和摘要；禁止执行 Hook、Wrapper、包管理器、项目二进制或构建脚本。
- 后端将已校验源码发送到目标 Linux，或让目标机取得同一固定 Commit，并复核摘要后构建。
- Web 主机不能作为用户项目的“临时构建机”或失败回退构建位置。

## 7. 持久化任务

任务至少包含：等待、分析中、等待用户决定、执行中、正在取消、已取消、成功、失败、被系统中断、需要重新验证。

- 浏览器断开不取消任务；SSE 断线后可以按事件序号继续，最终状态也可普通查询。
- 同一目标服务器上的修改任务互斥；只读任务仅在资源限制内并行。
- 后端重启后扫描未终结任务。只有具有幂等证据和安全恢复点的步骤可继续，其余进入“需要重新验证”。
- 等待用户决定具有过期时间；过期安全停止。取消是受控状态迁移，不直接杀死到未知状态。
- 任务保存计划摘要、步骤输入摘要、远端结果、版本指针、结构化事件和失败证据；秘密在持久化前脱敏。
- API/SSE 客户端无权直接修改任务状态、步骤游标或成功结果。

## 8. Web 凭据与主密钥

- `web/secret` 统一处理管理员密码哈希、应用主密钥、认证加密和 SSH/Git/AI/备份相关凭据。
- 主密钥不进入 SQLite、普通数据备份、日志、事件或 HTTP；通过权限受限文件或部署环境安全提供。
- 保存后只向浏览器返回名称、非敏感元数据、已配置状态和更新时间，永不回传原始值。
- 主密钥丢失时不能伪造恢复，必须要求重新配置受影响凭据；数据库恢复结果需要明确指出凭据不可用。
- 桌面与 Web 不同时打开同一个 SQLite 或工作目录。迁移配置使用经过验证的导入/导出，不共享正在使用的数据文件。

## 9. 前端范围

`web/frontend` 使用 Vue 3、TypeScript、Vite，单元测试使用 Vitest，关键流程使用 Playwright。前端只通过 HTTP/SSE 使用 `web/api`，不依赖 Java 模块或直接访问数据库、文件、SSH。

功能入口覆盖部署、已部署应用、服务器、AI、备份/迁移、任务和设置，但不建设大型专业运维控制台。页面必须区分浏览器电脑、Web 主机和目标 Linux，说明动作影响、失败原因和下一步，不展示原始异常或用隐藏失败制造简单感。

当前仓库中的页面只是可构建骨架，不代表任何 Web 业务已经实现。

## 10. Web 自身升级

Web 不内置替换自身程序或容器的自动更新器。管理员人工取得并验证签名发布包/镜像后替换版本，应用在启动/切换前后执行：

```text
停止接收新修改任务
→ 等待任务进入安全状态
→ 备份 SQLite、应用数据和版本信息
→ 管理员替换签名包或镜像
→ 新版本执行迁移前检查和版本化数据库迁移
→ 启动健康检查
→ 成功恢复任务；失败由管理员切回旧包/镜像并恢复旧数据库
```

应用必须提供可操作的回滚证据和步骤，但不能在运行进程内覆盖自身。数据库迁移失败时停止启动，不让旧程序读取已迁移失败的数据结构。

## 11. 实施顺序

1. 完成前端骨架门禁和 `web` 模块装配基础。
2. 实现主密钥、SQLite、一次性初始化令牌、管理员认证、会话和 CSRF 纵向切片。
3. 实现受管文件、上传和 Git 静态快照边界。
4. 实现持久化任务状态机、恢复和 SSE 事件。
5. 接入服务器、分析、部署和生命周期，共享前四期规则。
6. 接入备份/迁移及人工升级预检，完成浏览器和安全负向测试。

## 12. 五期不包含

- 官方 SaaS、多用户、多租户、角色权限、公开注册或找回密码邮件。
- 多节点后端、共享 SQLite、分布式任务队列或 Kubernetes。
- 浏览器终端、远程文件管理器、任意服务/容器管理和通用监控。
- 在 Web 主机执行用户项目或把 Web 主机当作构建回退。
- 自动 DNS/域名/云账号接管或 Web 进程自动替换自身。

## 13. 验收标准

### 13.1 初始化和认证

- [ ] 一次性令牌默认 15 分钟、单次使用、不可匿名获取；成功后初始化端点永久关闭。
- [ ] 管理员密码适应性哈希、登录限速、会话超时、近期认证和安全审计通过测试。
- [ ] Cookie、SameSite、Secure、CSRF、安全方法和可信代理/Host 验证符合文档。

### 13.2 文件和任务

- [ ] 大文件流式处理，路径穿越、链接、特殊文件、压缩炸弹、超限和清理越界被阻止。
- [ ] Web 主机从不执行用户项目代码，目标机源码摘要与分析快照一致。
- [ ] 浏览器断开和后端重启不会把任务误标成功；只安全恢复可幂等步骤。
- [ ] SSE 可恢复且只包含脱敏事件，客户端不能伪造任务状态。

### 13.3 业务与升级

- [ ] Web 部署、生命周期、备份和迁移复用前四期规则，远端状态来自实时查询。
- [ ] 浏览器不能读取原始 SSH/Git/AI/备份凭据，主密钥不进入 SQLite 或普通备份。
- [ ] 前端类型检查、Vitest、生产构建和关键 Playwright 流程通过。
- [ ] 人工升级中迁移或健康失败具有经过验证的旧包/镜像和旧数据库回滚路径。
