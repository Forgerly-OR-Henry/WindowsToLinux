# 审批证据与缓存验证

历史实验日期：2026-10-08。本记录的 `managed-helper-review.v1` 与正文工具格式属于当时版本；当前原生工具、审批契约和缓存计数规则以 Runtime 为准，不用本实验证明新版效果。实现合同见 [Runtime.md](../reference/Runtime.md#ai-命令审批长期规则)，公开用量接口见 [Mod.md](../reference/Mod.md)。本次未进行真实服务器部署验收。

## 当时的实验版本与方法

已安装 helper/build-entry 使用独立固定源码摘要的 `managed-helper-review.v1` 行为契约。完整性守卫、当前完整命令、动态可执行正文和原始授权绑定继续保留；首次安装仍提交全部安装脚本。身份或守卫变化拒绝审批。

公共审批规则、平台契约、动态事实依次发送。对象键递归稳定排序，目标集合按身份排序，顺序数组保持原顺序。格式纠正最多一次，仅追加尾部要求；明确拒绝、未知、截断或超时不触发纠正。

`AiUsage` 增加可选缓存命中、未命中和推理计数。标准详情与 DeepSeek 字段按实际字段解析，缺失保持未知，非法或矛盾计数拒绝。成功、格式失败和截断的有效计数均保留。逐调用日志记录时间、用途、操作、尝试序号、请求大小、固定前缀摘要及结果，不记录密钥、受保护载荷或推理正文。缓存输入包含在总输入中，推理包含在总输出中。

## 离线输入大小

使用相同代表性 `build-preflight` 动作重建旧的完整 helper 证据；两边各计入相同 8,000 字节公共规则裕量，新布局额外计入完整平台契约。统计为 UTF-8 消息正文大小，不是 tokenizer 计数，也不含 HTTP 外壳。

| 动作 | 原完整源码布局 | 精简布局 | 降幅 |
|---|---:|---:|---:|
| 普通已安装 helper 调用 | 539,915 字节 | 15,639 字节 | 97.10% |
| 同一调用附加一条命令 | 539,954 字节 | 15,678 字节 | 97.10% |

测试确认原执行脚本及授权 `exactAction` 不变，附加命令完整呈现。首次安装的 531,951 字节脚本和大型构建的 144,000 字节动态 stdin 均完整保留，未把这些场景套入普通调用降幅。

## 受控 API 对照

复用已保存审批模型 `deepseek-flash`，官方端点 `https://api.deepseek.com/chat/completions`，推理设置 `HIGH`。生产配置未改动。隔离测试先核验端点和模型，再通过平台受保护凭据接口鉴权，不读取原始密钥配置文件。

A 为公共规则、动态事实、固定契约；B 为公共规则、固定契约、动态事实。每对内容相同，仅调整位置；双方都追加相同的结束提示。目标为虚构的 `cache-fixture-server`，动作是固定 helper `probe`，无真实服务器信息或业务输入。仅调用审批 API，不获取执行许可、不连接 SSH。

计划顺序 A1/B1/A2/B2/A3/B3，最多 6 次及累计 100,000 tokens；每次发送前预留 UTF-8 输入字节、2,048 协议余量和最多 4,096 输出。实际按停止规则仅执行 A1/B1，没有格式纠正、路由替换或补跑。

| 调用 | 总输入 | 命中输入 | 未命中输入 | 总输出 | 其中推理 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| A1 | 3,138 | 0 | 3,138 | 1,120 | 982 | 完整 JSON，stop |
| B1 | 3,137 | 1,024 | 2,113 | 4,096 | 4,096 | 截断，length，FAILED |
| 合计 | 6,275 | 1,024 | 5,251 | 5,216 | 5,078 | 2 次调用 |

实际输入加输出为 **11,491 tokens**，其中失败调用消耗 7,233；重试消耗为 0。B1 虽报告缓存命中，但推理占满输出上限，随后停止。测试程序正确保留了失败用量并完成关闭；Maven 测试通过不表示 B1 审批成功。

只有一对请求且 B1 截断，**不足以证明缓存改善**。缓存为异步提供方状态，调用次序也影响结果；此前缓存下降的历史根因仍未确认。未追加请求追求命中率，也未调低生产推理设置或输出预算。

## 当时的验证范围与证据

当时按接口值、协议计数、稳定证据编码、helper 审批合同、三档授权、辅助/Agent 工作流及文档门禁选择定点测试，并完成受影响模块编译；没有执行项目或模块全套测试。失败用量保留不等于审批通过，本地用例通过不等于真实部署验收。

沙箱内 H2 可写检测、辅助夹具接线和 API 调度前的失败不计为提供方请求重试；实际付费请求仅为表中的 A1/B1。原始检查、失败组和对照日志保留在 `.ai-workspace/evidence/approval-cache-evidence/`，阶段结论见[审批缓存验证归档](../../.ai-workspace/progress/history/2026-10-08-approval-evidence-cache-validation.md)。本页只保留方法、实际数据、结论及验证边界。
