# 固定样本

初始“校园活动”含任务 1 和 2，任务 2 依赖任务 1，均为 todo/version=1；“实验室建设”含任务 3。依次 todo→doing→review→done，每次版本加一，未完成依赖阻止 done。重复使用旧版本编辑返回 409，不能重复更新或添加事件。

request.json 新建校园活动任务，创建后该项目 total 从 2 增至 3。跨项目负责人、依赖、详情查询被拒绝；依赖环被拒绝。分页 size 为 1..100，标签最多 8 个、每个 24 字符，依赖最多 20 个。generate.py 通过实际 Java 接口扩展规模。

运行时请将需修改的样本复制到临时目录；预期结果同时由仓库测试运行器核对。
