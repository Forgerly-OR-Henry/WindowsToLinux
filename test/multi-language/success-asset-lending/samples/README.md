# 固定样本

新数据目录含三件资产（1、2、3）和两个分类。将 request.json 发到 POST /api/loans，依次提交、审批、领用，先完好归还资产 1，再损坏归还资产 2：借用单最终 closed，资产 1 available，资产 2 maintenance，产生一张维修工单。完成维修后资产 2 available。

每次状态操作带固定演示 actor 和独立 requestId。重试同一次操作使用原键；结果和历史不能重复。同键不同内容、整单包含不可用资产、新键归还已归还项都返回 409。generate.py 通过真实 API 扩展规模，样本不包含登录身份或认证。

运行时请将需修改的样本复制到临时目录；预期结果同时由仓库测试运行器核对。
