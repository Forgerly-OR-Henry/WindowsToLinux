# 固定样本

同一文件夹上传“中文 文件.txt”两次，应得到同一 fileId 的版本 1 和 2；版本 id 不同、SHA-256 相同，下载均保持原字节。不同文件夹同名文件的 fileId 不同。会话中断后已确认分块保留，重新选择相同文件继续；未确认的半块不计入进度。

generate.py 默认生成 64 MiB 确定性二进制文件（种子 20260919），输出独立计算的 SHA-256。同编号同分块幂等、不同内容 409；10 次并发完成只能发布一个版本。未完成会话不可下载，取消后不能继续上传。默认上限 256 MiB，可上传空文件，名称禁止路径分隔符、换行和 NUL。

运行时请将需修改的样本复制到临时目录；预期结果同时由仓库测试运行器核对。
